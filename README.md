Bem-vindo ao repositório do **Projeto Carros**! 

Este é um projeto muito especial para mim, pois foi desenvolvido há 4 anos durante o meu **primeiro curso de Front-end**. Ele representa os meus primeiros passos na área de desenvolvimento web e serviu para consolidar os fundamentos básicos da criação de interfaces.

## 📖 Sobre o Projeto

O **Projeto Carros** é uma landing page (ou vitrine virtual) focada em exibição de veículos. A ideia principal era aplicar na prática os conceitos iniciais de estruturação, estilização e interatividade na web, sem o uso de frameworks complexos, focando no "Vanilla" para garantir uma base sólida.

Ao olhar para este código hoje, vejo o quanto evoluí, mas mantenho este repositório como um marco importante da minha jornada na programação! 🚀

## ✨ Funcionalidades (O que foi implementado na época)

- 🏎️ **Vitrine de Veículos**: Estruturação de cards e layout para exibir diferentes modelos de carros.
- 📱 **Design Responsivo**: Adaptação básica do layout para funcionar em diferentes tamanhos de tela.
- 🖱️ **Interatividade Básica**: Uso de JavaScript para manipulação do DOM e eventos simples (como cliques e navegação).

## 🛠️ Tecnologias Utilizadas

Como foi um projeto introdutório, as tecnologias base utilizadas foram:

- **HTML5**: Semântica e estruturação do conteúdo.
- **CSS3**: Estilização, Flexbox/Grid e Media Queries.
- **JavaScript (Vanilla)**: Lógica de programação e manipulação de elementos na tela.

## 🚀 Como executar o projeto localmente

Como o projeto é feito puramente em tecnologias base da web (HTML/CSS/JS), não é necessário nenhum ambiente complexo para rodá-lo.

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/samuelmedeirosjs/projeto-carros.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto-carros
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize a extensão **Live Server** no VS Code.
